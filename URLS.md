# Ship & Sail HQ URL Guide

If the website is hosted at `https://shipandsail.github.io/hq/`, use this pattern for app pages:

- App listing page: `https://shipandsail.github.io/hq/<app-folder>/<app-file>.html`
- Privacy policy: `https://shipandsail.github.io/hq/<app-folder>/pp.html`
- Terms page: `https://shipandsail.github.io/hq/<app-folder>/toc.html`

## Current Kiksy URLs

- App page: `https://shipandsail.github.io/hq/kiksy/kiksy.html`
- Privacy Policy: `https://shipandsail.github.io/hq/kiksy/pp.html`
- Terms of Service: `https://shipandsail.github.io/hq/kiksy/toc.html`

## Add a new app

1. Create a new folder under `hq/`.
2. Add the app HTML page and optional `pp.html` / `toc.html` files.
3. Link the app from `index.html`.
4. The URL will then follow the same pattern above.
